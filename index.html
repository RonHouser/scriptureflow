About Scripture Flow

Welcome to Scripture Flow

Scripture Flow is a typing app focused on the King James Bible. Type verses to learn the Word, track progress, improve spelling, and build typing skills in a serene environment with ambient music.

Scripture Flow does not store data on a server. All data is saved locally in this browser on this device.

Modes

Random Mode

Verses appear randomly from unseen parts of the Bible. Complete verses to mark them as done and track metrics like WPM and accuracy. View everything in the “Progress” section.

Memory Mode

Memorize selected verses. Words fade out progressively as you type correctly without errors. Master a verse by fading all words. Press the icon next to a verse to add it to your memory bank. Typing metrics are not tracked in this mode.

Choice Mode

Select specific chapters, or individual verses to type. The option to type entire chapters is available in any chapter view.

Features

  • Progress Tracking: View completed verses, journey days, streak, and typing stats. Explore Bible completion by book and chapter.
  • Profiles: Create multiple profiles to separate progress for different users or goals.
  • Memory Bank: Add verses for memorization. Track faded words and remove verses as needed.
  • Volume Control: Adjust background music volume.
  • Export/Clear: Export progress data or clear it with confirmation.

Bible Typing Tutorial

The Bible Typing Tutorial teaches proper typing technique through Bible stories, from David and Goliath to the Red Sea. Each lesson adds a new row of keys, building accuracy first, then speed, then both.
